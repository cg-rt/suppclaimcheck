# gateway

The only module that calls outside services: the LLM, literature sources and Telegram alerts (D-011, D-033). Holds every API key. Owns the `gateway` schema (LLM call records and the article cache); runs as database role `scc_gateway_app`. On the `egress` network.

- **Run:** `python -m scc_gateway` (port 8000). Migrate step: `python -m scc_gateway.migrate`.
- **Endpoints:** `POST /llm/structured` (one schema-constrained Claude call: priced, capped, retried on transient errors and recorded; an `Idempotency-Key` returns the stored answer of the same call instead of charging again, P3.05), `GET /budget/status` (each lane's level and whether a new check may start for an account, P3.04), `POST /literature/search` (PubMed with the open-access filter), `POST /literature/spell` (PubMed's spelling suggestion for a supplement name, NCBI ESpell; null when there is none), `POST /literature/fetch` (Europe PMC licence, metadata and JATS full text; disallowed licences are skipped and counted), `POST /notify` (a Telegram alert: event, code and short text, never user text; quiet codes and repeats within an hour are not sent), plus `/health`, `/health/deps` and `/version`. Read-only admin endpoints for web's admin pages (`admin_api.py`, D-049): `GET /admin/llm-calls` (by job, status or lane), `/admin/usage` (this month per lane, per day, per stage and model, and per account) and `/admin/config`. Privacy (P3.06, D-054): `POST /users/{id}/erase` unlinks a deleted account's LLM calls and drops their stored answers; an hourly purge inside the process clears stored answers and old account links (`privacy.py`, `gateway-v2` `[retention]`). Spec: `openapi.json`.
- **Budget:** monthly caps per lane, worst-case reservation before each call, fails closed (D-038, RB-09). The full guard (D-053): warnings at 50% and 80% once a month, new checks stopped near the cap, a daily quota of checks per account (counted from extraction calls), all in the config.
- **Config:** price table, caps, licence allowlist and rate limits in `src/scc_gateway/config/gateway-v1.toml` (with the warnings, quota and idempotency settings), registered in the database by the migrate step; the gateway reads the active version at start-up, and `python -m scc_gateway.config` manages versions (D-048, RUNBOOK RB-15). Secrets: `anthropic_api_key`, `ncbi_api_key`, `telegram_bot_token` and `telegram_chat_id` (an empty file means not configured). When the budget cap refuses a call, the gateway sends a `budget_cap_reached` alert itself. `SCC_BUDGET_CAP_OVERRIDE_EUR` lowers the caps for drills.
- **Tests:** `uv run pytest services/gateway`.
